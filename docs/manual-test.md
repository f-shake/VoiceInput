# 手工验收清单

自动化测试覆盖不到真实麦克风、真实键盘钩子与真实剪贴板，这一批必须人工过。
每条都记结果，失败的写现象，别只打叉。

准备：`dotnet build src/VoiceInput.App` 后运行 `src\VoiceInput.App\bin\Debug\net10.0-windows\VoiceInput.exe`，
或用 `dotnet run --project src/VoiceInput.App`。第一次启动还没有 Key，程序会自己弹出设置窗口；填好 Key 保存即可继续。

参照图 `overlay-fixed.png` 是 200% 缩放下状态圆的实际位置：贴在任务栏正上方、屏幕水平居中。

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| 1 | 启动程序（配置里没有 Key 时） | 直接弹出设置窗口；填 Key 保存后托盘出现麦克风图标；日志首行有配置文件路径 | |
| 2 | 打开记事本，光标放进去，按住右 Ctrl 说一句话 | 听到一声高音；右下角出现蓝色圆，中心白色波形，外圈进度环在走 | |
| 3 | 松开右 Ctrl | 听到一声低音；圆变三点循环；随后变绿打勾；1.5 秒后消失 | |
| 4 | 看记事本 | 出现识别文本，标点齐全，没有换行 | |
| 5 | 打开 Windows Terminal，重复第 2~3 步 | 文本落进终端命令行；若不落，圆变红并提示“请手动按 Ctrl+V”，剪贴板里有文本 | |
| 6 | 按住右 Ctrl 说半句话，期间按一下 C 键，再松开 | 圆变红，上方气泡写“检测到组合键，已取消本次听写”；没有任何文字落进窗口 | |

| 8 | 说满 118 秒以上（可读长文） | 到上限自动停止，提示“录音超过 118 秒”，随后正常粘贴 | |
| 9 | 先复制一段文字，再做一次听写 | 听写完成后剪贴板恢复成刚才那段文字 | |
| 10 | 先复制一张图（截图），再做一次听写 | 听写完成后剪贴板里的图还在 | |

| 16 | 让记事本以管理员身份运行，再试第 2~3 步 | 已知限制：收不到按键，应完全没有反应；换成普通窗口后恢复 | |
| 17 | 右键托盘 → 设置 | 窗口正常，标签与输入框不重叠、不被裁；200% 缩放下同样成立 | |
| 18 | 设置里把热键改成 F9 并保存 | 立刻按 F9 就能录音，不需要重启 | |
| 19 | 设置里关掉提示音再听写一次 | 不再有提示音，状态圆照常出现 | |
| 20 | 设置 → 结果优化：方式选“修复和润色”，填 Key，保存；说一句带“嗯、那个”和错别字的话 | 语气词与重复词被去掉，错别字被纠正，句子通顺，语义不变 | |
| 21 | 方式改成“仅修复错别字和标点”，说一句带错字的话 | 只改错字与标点；语序、语气词都保持原样 | |
| 22 | 方式改成“仅修复标点”，说一句没有标点的话 | 只多出标点，汉字一个不变 | |
| 23 | 关掉“保留句末标点”，三种方式各听写一次 | 结果末尾没有句号；选“不优化”时同样去掉末尾标点 | |
| 24 | 断网后选一种优化方式听写 | 状态条“优化中”后变**橙色**圆，气泡写“已粘贴 N 字（优化失败）”；原文照样粘贴；日志有 E26 与原因 | |
| 25 | 点“模型”下拉 | 候选来自接口地址（初始为空，不再有内置模型）；把地址改成 `http://127.0.0.1:1`（不存在的端口）再点，弹出“无法获取模型列表”的现代样式对话框，写明原因 | |
| 26 | 设置窗口 100% 与 200% 缩放下各看一次 | 三块布局不重叠、不裁切；选“不优化”时 Key、接口地址、模型、超时变灰 | |
| 27 | 录音时对着麦克风说话、再安静一会儿 | 圆内波形条随音量变高变矮；安静时压得很矮但没有消失 | |
| 28 | 正常联网听写一次（优化成功） | 绿圆，气泡写“已粘贴 N 字（已优化）” | |
| 29 | 把超时改成 5 秒，说一段长句 | 5 秒左右按失败处理：橙圆 + 原文粘贴；日志写“读取超时 5 秒”；超时框范围 1~60 | |

补充检查：

- 状态圆出现时**不要点它**——它应该是鼠标穿透的，点下去没有任何反应，也不会把焦点从记事本抢走。
- 听写期间在记事本里继续打字，字不应该丢；如果丢字，说明状态圆抢了焦点，属缺陷。
- 日志文件 `%LOCALAPPDATA%\VoiceInput\logs\voiceinput.log` 里每次失败都应有错误码与 `request_id`。
